Mini-Game Mobile App

Developed a multi-game mobile app for iOS using React Native and Expo as part of a team project. The app includes several games such as Flappy Bird, Color Sort, Bubble Shooter, 2048, Minesweeper, Tic-Tac-Toe, and Connect Four, supporting both single-player and multiplayer modes.

The goal of the project was to create an engaging and user-friendly mobile gaming experience while learning and applying modern mobile development techniques, including navigation, state management, animations, and cloud data integration.

I took the lead on the Bubble Shooter game, implementing full game mechanics, physics using Matter.js, collision detection, scoring, and animations. Firebase integration was used to store and retrieve high scores, while React Context managed player nicknames. Smooth UI and visual effects were achieved using LinearGradient and animated score popups for an immersive experience.

Key Features

  • 🎮 Multiple mini-games in a single app
  • 📊 User data storage and tracking with Firebase
  • ⚡ State management using React Context
  • 🛠 Built with React Native and Expo
  • 📦 Integration of multiple third-party libraries for enhanced functionality
  • 🌀 Project managed using Scrum agile methodology

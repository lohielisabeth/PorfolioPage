Project Overview

The project is a dynamic and responsive web application designed for movie enthusiasts. The frontend was developed using React, incorporating React Router for navigation and Context API for managing user state. The backend was built with Node.js and Express, using PostgreSQL to store user data, reviews, and favorites.

The application integrates with open data sources, including The Movie Database (TMDb) API for fetching detailed movie information (such as title, poster, and release date) and the Finnkino API for showtimes. Users can register and log in to the application to submit their own movie reviews, which are stored securely in the PostgreSQL database and displayed only on the application itself.

Key Features

  • 🔒 Secure user registration and login system with password validation
  • 🎥 Advanced movie search functionality with multiple search criteria
  • 📅 View showtimes for movies at Finnkino theaters in real-time
  • ⭐ User review system with ratings and detailed movie feedback
  • 📱 Responsive design for optimal experience across all devices

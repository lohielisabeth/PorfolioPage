Project Overview

The Arduino Speed Game is a reaction-based game designed and implemented entirely on an Arduino platform. The game challenges players to replicate sequences of visual cues using 5 input buttons, with immediate feedback provided via LEDs and a 7-segment display showing the current score. Button presses are managed using hardware interrupts and programmatic debouncing to ensure accurate input detection.

Random sequences of numbers are generated using a Timer1 interrupt, with correct player inputs progressively increasing the game speed and incorrect inputs resetting the game. The display system is implemented with two 74HC595 serial-to-parallel shift registers, driving the 7-segment displays without relying on Arduino’s built-in libraries, allowing for more efficient control and modularity.

The game logic is fully modular: sequences are stored and compared dynamically, LEDs and buttons are managed through separate functions, and timer-based difficulty adjustments provide a consistent challenge. This architecture allows the game to be easily extended, for example by adding new sequences, increasing difficulty, or integrating additional feedback mechanisms such as sounds.

Key Features of the Speed Game

  • 💡 Multiple LEDs controlled via Arduino to provide dynamic visual feedback during gameplay
  • 🎮 Game logic that adapts and increases difficulty based on player performance
  • 🕹️ Button-based user input with hardware interrupts and debouncing for accurate and responsive interaction
  • 📊 Real-time reaction tracking and score display on a 7-segment display driven by 74HC595 shift registers
  • 🔧 Custom hardware setup including LEDs, resistors, buttons, and Arduino microcontroller for a fully functional game circuit

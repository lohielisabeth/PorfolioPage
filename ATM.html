Project Overview

This project is a functional ATM application that allows users to securely perform basic banking operations, including checking account balances, withdrawing money, and viewing recent transactions. The frontend interface was built with Qt/C++, providing an interactive user interface with support for RFID card authentication and PIN code entry. Users can select predefined withdrawal amounts or enter custom amounts using the "Other" option. The backend is implemented with Node.js, Express, and PostgreSQL, handling account data, transaction history, and secure authentication.

The architecture follows a client-server model: the ATM machine acts as a client with multiple UI components (balance display, withdrawal interface, transaction history), and communicates over the network with a server that manages the database and provides API endpoints. User account data, balances, and transaction history are securely stored in PostgreSQL.

Key Features of the ATM Application

  • 💳 User authentication using RFID card reader and PIN code
  • 💰 Secure money withdrawals with real-time balance updates, including predefined and custom amounts
  • 🔒 Account balance checking and credit limit management
  • 📋 Transaction history display (last 5 transactions)
  • ⚙️ Backend implemented in Node.js and PostgreSQL for secure data persistence
  • 🖥️ Responsive and interactive frontend built in Qt/C++
